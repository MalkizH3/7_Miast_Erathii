# Szablon kart — 7 Miast Erathii

## Elementy graficzne

- `card-cost-strip.png` — pasek na koszty karty, oryginalny PNG dostarczony przez użytkownika.

- `card-top.png` — górna część karty, oryginalny PNG dostarczony przez użytkownika jako `image(4).png`. Plik zapisany w oryginalnej postaci, bez zmian grafiki.
- Elementy szablonu przechowujemy osobno od ilustracji poszczególnych kart.
- Oryginalne grafiki zachowujemy bez skalowania, rekompresji i zmian kolorów.

## Marginesy

- Górny i dolny: po 46 px.
- Lewy i prawy: po 47 px.
- Wartości dotyczą oryginalnej rozdzielczości karty; przy skalowaniu całej karty skalujemy je proporcjonalnie.
- Znaczenie marginesów przy składaniu warstw wymaga potwierdzenia na podstawie widocznego szablonu.

- `card-name-banner.png` — pasek nazwy, 800 × 87 px. Położenie na karcie: x = 146 px (wyśrodkowany), y = 81 px.
